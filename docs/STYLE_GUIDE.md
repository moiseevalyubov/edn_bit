# UI Style Guide — стиль edna для веб-форм

Веб-интерфейс приложения (страница настроек `/settings`) оформлен в стиле дизайн-системы **edna**, чтобы выглядеть «родным» внутри их экосистемы. Этот документ — короткий справочник по токенам и компонентам. Используйте его, когда добавляете или меняете формы и страницы.

> **Где это в коде:** все стили зашиты inline в [`app/routers/settings_page.py`](../app/routers/settings_page.py) внутри блока `<style>` (переменные `--edna-*`). Источник правды по внешнему виду — сама страница `/settings`.

---

## Палитра (дизайн-токены)

Заведены как CSS-переменные в `:root`. Используйте переменные, а не «сырые» hex — так всё останется согласованным.

| Переменная | Цвет | Назначение (название в edna) |
|---|---|---|
| `--edna-text` | `#121212` | Основной текст (Grey900) |
| `--edna-text-secondary` | `#5B5B5B` | Вторичный текст, заголовки таблиц (Grey600) |
| `--edna-text-tertiary` | `#B7B7B7` | Приглушённый текст |
| `--edna-divider` | `#ECECEC` | Линии-разделители строк (Grey100) |
| `--edna-green` | `#09A460` | Позитивный статус «активно» (Positive500) |
| `--edna-red` | `#E11900` | Ошибка / негатив (Red500) |
| `--edna-blue` | `#276EF1` | Нейтральный / информационный статус (Blue500) |
| `--edna-primary` | `#121212` | Заливка главной кнопки (Grey900) |

**Важно:** у edna **нет жёлтого/янтарного**. Для «предупреждающих» / нейтральных состояний используйте синий `--edna-blue`.

**Фон страницы:** белый (`#fff`).

---

## Шрифт

Основной шрифт — **Noto Sans** (подключается с Google Fonts). GraveAccent (фирменный шрифт edna) используется ими точечно, мы его не грузим.

```
--edna-font: 'Noto Sans', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif;
```

Если корпоративная сеть блокирует Google Fonts — шрифт молча откатится на системный, вёрстка не ломается.

## Компоненты

### Карточки (секции)
Скругление **8px**, без рамки, лёгкая тень `0 1px 4px rgba(0,0,0,.1)`, `overflow: hidden` (чтобы содержимое — например таблица «от края до края» — обрезалось по скруглённым углам).

### Таблицы
- Заголовки: серые (`--edna-text-secondary`), мелкие (12px), `font-weight: 600`, **без** тёмно-жирного и без серой «шапки».
- Ячейки: текст `--edna-text`, 13px.
- Строки разделены тонкими светлыми линиями `--edna-divider`. Никаких внешних рамок.

### Статусы (бейджи)
**Контурные «таблетки»**, не заливка: прозрачный фон, цветной текст + рамка 1px, `border-radius: 24px`, 12px / `font-weight: 600`.
- Активно → `--edna-green`
- Отключено → `--edna-text-tertiary`
- Нейтрально / внимание → `--edna-blue`

### Кнопки
Общее: `border-radius: 8px`, 14px / `font-weight: 600`, паддинг `8px 20px`.
- **Главная** (`btn-primary`): заливка `--edna-primary` (#121212), белый текст; при наведении текст светлеет до `#d9d9d9`.
- **Вторичная** (`btn-outline-secondary`): белый фон, тёмный текст, рамка белая, мягкая тень `0 1px 4px -1px rgba(18,18,18,.2)`.
- **Опасное действие** (`btn-outline-danger`, напр. «Отключить»): контурная красная `--edna-red`, заливается красным при наведении.

### Поля ввода
Тёмная рамка `--edna-text`, скругление **8px**, 14px, паддинг `8px 12px`. Фокус — нейтральная подсветка `0 0 0 2px rgba(18,18,18,.12)` (не синяя по умолчанию из Bootstrap). Плейсхолдеры — `--edna-text-tertiary`.

## Как снять стиль нового элемента с edna

Когда понадобится цвет/параметр, которого здесь нет:

1. Откройте интерфейс edna в Chrome, нажмите **F12**.
2. **ПКМ по нужному элементу → Inspect** (он станет выбранным, `$0` в консоли).
3. На вкладке **Console** выполните:
   ```js
   const c = getComputedStyle($0);
   copy(JSON.stringify({
     color: c.color, background: c.backgroundColor, borderColor: c.borderColor,
     borderRadius: c.borderRadius, fontFamily: c.fontFamily, fontSize: c.fontSize,
     fontWeight: c.fontWeight, padding: c.padding, boxShadow: c.boxShadow
   }, null, 2));
   ```
   Результат скопируется в буфер.
4. Если у элемента прозрачный фон (снялся внутренний текст, а не «коробка») — поднимитесь до элемента с настоящей заливкой:
   ```js
   let el = $0, bg = '';
   while (el && ((bg = getComputedStyle(el).backgroundColor) === 'rgba(0, 0, 0, 0)' || bg === 'transparent')) el = el.parentElement;
   copy(bg);
   ```

Скриншоты из интерфейса или Figma — тоже подходящий источник, цвета можно снять с картинки.
